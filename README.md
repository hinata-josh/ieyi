## 列印／輸出 PDF

按右上角 🖨️（或 `Ctrl`+`P`）→ 目的地選「另存為 PDF」。列印版會自動：

- **彩色列印**：沿用淺色主題的配色（不是灰階），並用 `print-color-adjust: exact` 強制印出底色與色塊——**即使 Chrome 沒勾「背景圖形」也印得出來**。封面保留蠟筆色條與淡漸層。
- **每個大項目（章節）強制從新的一頁開始**，封面自己一頁；表格跨頁時每頁重印表頭，小標題不會單獨留在頁尾。
- **不會被截掉**：表格改成 `table-layout:fixed` 縮到紙寬、捲軸容器改成可見；已用 A4 內容寬度（約 702px）實測 `scrollWidth === clientWidth`、**沒有任何元素超出紙寬**。
- **輸入框的字不會被切一半**：列印前會把每個輸入框換成可自動換行的純文字（`printSwap()`）並把原本的輸入框藏起來（否則值會印成兩份），列印完自動還原；空格顯示「—」。
- **個人照片縮成 30 mm 大頭照**（螢幕上仍是大張）。
- 隱藏互動元件（兩台模擬器、頁籤、工具列、評審指引卡），展開所有 Q&A 解答。

> 目前約 32～33 頁（A4，一章一頁起）。只想印重點就先切到某個語言（中或 EN），雙語對照模式會多一倍字。

## 麵包板模擬器是怎麼整合的

`build-integrated.js` 做三件事：

1. 把 `..\breadboard-sim` 的 `breadboard.html + circuit.js + app.js` 併成單檔，並加上一段版面覆寫（麵包板在上、面板在下的單欄流）與高度回報程式。
2. 把整份 HTML 放進 `<script type="text/plain" id="bbSrc">`（`<script` / `</script` 先換成標記字串，否則 HTML parser 會提早結束外層 script），頁面端 `initBreadboard()` 還原後灌進 `iframe.srcdoc`。
3. 在 `<html>` 加上 `data-judge="1"` 切成評審操作版。

**為什麼用 iframe 而不是直接合併：** 麵包板模擬器有自己的 `body`／`button`／`main` 裸標籤 CSS，也有 `roCap`、`roPeak` 等與參賽網站同名的 id，直接合併會互相破壞版面與 DOM 查詢。iframe + srcdoc 讓兩邊的 CSS／id／鍵盤事件完全隔離，且仍然是**單一 HTML 檔、離線可用**。

要改模擬器本身（電路解算、零件、教學步驟），改 `K:\Html5\breadboard-sim` 下的原始檔，然後重新產生。

## 照片放在哪裡？

參賽者照片**已內嵌在 `JoshIEYI.html`**（460px JPEG → base64），整頁 0 個外部檔案參照，所以「只拖一個 HTML」就能完整上線。

`assets/` 只是原始素材備份，網站不會讀它：

| 檔案 | 用途 |
|---|---|
| `assets/photo-hinata-original.png` | 原檔（1029×1544），重新裁切或印展板用 |
| `assets/photo-hinata-460.jpg` | 目前內嵌在網頁裡的那張（460px，50 KB） |

**換照片**：壓到寬 460px 的 JPEG → base64 → 替換 `JoshIEYI.html` 裡 `var MEMBER_PHOTO = 'data:image/jpeg;base64,...'` 那一行，再重新產生評審版。壓縮指令（借 Remotion 附的 ffmpeg）：

```
K:\Html5\josh-video\node_modules\@remotion\compositor-win32-x64-msvc\ffmpeg.exe -y -i 新照片.png -vf "scale=460:-1:flags=lanczos" -q:v 4 assets\photo-hinata-460.jpg
```

## 技術備註

- 純前端單檔：無框架、無 CDN、無外部請求（照片與麵包板模擬器都內嵌）。
- 圖表為自繪 SVG；配色通過色盲（CVD）與對比檢核，深淺色各自取色。
- 發電模擬器物理模型：峰值電壓 = 13.5 V × 材料 × 顏料 × 粗糙度 × 濕度（無蠟層 ×0.12）；10 µF 電容充電時間常數約 45 秒，LED 門檻 1.9 V。
- 麵包板模擬器的電流是 `circuit.js` 用**節點電壓法**實算的（不是動畫），二極體反接、電容極性錯、同一縱欄短路都算得出來。
- 已用無頭 Chrome 實跑驗證兩個檔案：無執行期錯誤；18／17 個章節、表一～表四、情境一～五、剖面 SVG、Q&A、模擬器掛勾都正常；評審版的內嵌模擬器 `body[data-ready=1]`、420 個孔位、一鍵標準接線後三項接線檢查全綠、自動拍打 60 秒電容 1.57 V、LED 有電流。
- 模擬器僅供預習趨勢與練習解說，**不可當作參賽數據**。
